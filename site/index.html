Your agents. Not a walled garden.

Astro recognizes panes running Claude Code, Codex, Hermes or agy and gives each one a clear title badge and session label. Run them alongside ordinary shells, logs and monitors. Their tools and subscriptions stay yours.

Agent CLIs are installed separately. Astro isn't an agent service.

From screenshot to conversation.

Right-click a copied PNG to paste its private file path into the clicked pane. Copy command output from the title bar, or middle-click to paste the primary selection. Less switching, less hunting for context.

Image paths remain on your machine. Your CLI decides what to do with them.

Make room for Astro

Keep Kitty.
Bring the cat.

Astro is a configuration and title-bar extension for unmodified Kitty, not a terminal fork. Install it to your user account, then open Astro from your application launcher.

Install Kitty separately. Requires Git, Bash and Python 3.10+. Tested with Kitty 0.49.2 on Linux.

PNG pasting needs wl-clipboard on Wayland or xclip on X11; without it, right-click falls back to text.

For the astro command and application-menu entry, include ~/.local/bin in your PATH. The full-path start command works without it.

Install from source
git clone https://github.com/itmitalles-de/astro.git
cd astro
./install.sh
"$HOME/.local/bin/astro"

The included default session opens three Claude Code, three Hermes and three Codex panes, plus htop and a shell. Missing tools leave normal shells. Before the first start, edit ~/.config/kitty/sessions/default.conf if you want a different workspace.

Before you install

The installer replaces Astro-owned Kitty configuration files and backs them up first. Your existing personal session layout is kept on upgrades, and running panes aren't closed. Read the configuration if you already have a customized Kitty setup.

A few useful details

Still your terminal.

No new shell to learn. No account to create for Astro. Just a small open-source layer on a terminal we already like.

Does it work on a Wayland desktop?

Yes. Astro defaults to X11/XWayland. Native Wayland passed isolated headless Sway tests with Kitty 0.49.2; hover hints remain X11-only. Real GNOME/KDE desktops and physical hardware have not been verified.

Read the native Wayland test results
What about my existing configuration?

Replaced files go into a private timestamped backup next to the Kitty configuration. The installer preserves your session layout on upgrades. You can inspect every setting and use only the parts you want; check the README before installing.

What does Astro change about the clipboard?

At app startup, the launcher puts /resume into both clipboard selections. New panes don't repeat that. Programs inside Astro may read the normal clipboard without asking, including remote programs over SSH. Only run trusted software when your clipboard holds sensitive data. PNG files are saved privately and aren't automatically deleted.

Can I turn the greeting or prompt off?

Yes. Set ASTRO_ANIMATION=off to disable the greeting or ASTRO_PROMPT=off to keep your own prompt. REDUCE_MOTION=1 also disables the greeting. The underlying shell and Kitty remain yours.
